# Reports Directory

Auto-generated reports are saved here by GitHub Actions:

- `weekly-report.md` — Latest weekly digest
- `weekly-report-YYYY-MM-DD.md` — Archived weekly reports
- `gemini-analysis-YYYY-MM-DD.md` — README quality analysis
- `link-validation-YYYY-MM-DD.json` — Link check results
- `latest-validation.json` — Most recent link check

These files are generated automatically — do not edit manually.
