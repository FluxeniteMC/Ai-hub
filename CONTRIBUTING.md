# 🤝 Contributing to AI APIs Directory

Thank you for helping maintain the most comprehensive AI API directory!

## How to Add a New API

1. **Fork** this repository
2. Edit `README.md` — find the correct section
3. Add a row following the **exact** table format below
4. Submit a PR titled: `add: [API Name] - [Category]`

### Table Format

```
| [API Name](https://link.com) | Provider | Category | Free/Paid details | Notes |
```

### Checklist Before Submitting

- [ ] Link is correct and working
- [ ] Pricing info is accurate and current
- [ ] Placed in the correct section (Free / Freemium / Paid / Enterprise)
- [ ] Category tag is appropriate
- [ ] No duplicate entry already exists
- [ ] Table alignment is preserved

## How to Update Pricing

Submit a PR titled: `update: [Provider] pricing - [Model]`
Include a source link for the new pricing.

## How to Report a Dead Link

Open an issue using the **Dead Link** template, or submit a PR fixing it directly.

## Code of Conduct

Be respectful. This is a community resource. Inaccurate or misleading information will be rejected.
